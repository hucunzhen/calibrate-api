# 形状模板页 ROI：操作、保存、加载

入口：**高级功能 ▾ → 形状模板**。ROI 用来圈模板域、画胶路/刻线，再创建 `.shm` / `.dfm`。

有九点标定时（配方 `models/camera_correction.json` 指向有效九点 JSON）：

- **内存与存盘都是 mm**
- **只有叠到图像上、交给 HALCON 创建模板时才换成像素**
- 避免「像素 → mm → 再存 → 再当像素」来回换算掉精度

没有九点标定时：全程像素；**不能**用「保存 ROI」写成 mm 文件。

建议文件放在流程配方目录的 `roi/`，例如 `flows/v4/roi/`、`flows/20261028_/roi/`，扩展名 **`.xvroi.json`**。与左侧**参数配方**对应：

| 参数配方 | 约定文件（仅当已保存过才存在） |
|----------|-------------------------------|
| 外框模型 | `roi/outline.xvroi.json` |
| 粗匹配模型 | `roi/coarse.xvroi.json` |
| 精匹配模型 | `roi/fine.xvroi.json` |
| 自定义参数配方 | `roi/<配方名>.xvroi.json` |

切换参数配方时会**自动加载**上述文件；没有对应文件则保持当前 ROI。

## 1. 绘制操作

顶部工具栏 **形状**：

| 模式 | 做什么 | 典型用途 |
|------|--------|----------|
| **矩形** | 无 ROI 时在图上**按下拖到对角松开**即画出（轴对齐，与圆形相同）；已有 ROI 时点图或「参数…」改中心/宽高/角度（0°=轴对齐） | 灰度图模板、规则外框 |
| **圆形** | 无 ROI 时**按下圆心拖半径松开**即画出；已有 ROI 时点图或「参数…」改圆心/半径 | 圆孔、外圆 |
| **多边形** | 单击加点；路径可选直线/圆弧；回到起点容差内自动闭合。画线时 `Alt`+点强制选中已有边。点边拖动平移该段，松手未拖则弹窗；右键可删段 | 不规则外形、手绘边线模板 |
| **环形** | 先画外圈再画内圈并闭合 | 垫圈、密封圈（内外圈梯度通常相反） |
| **开放轨迹** | **不闭合**胶路/刻线，可多条 | 精匹配轨迹、胶线 |

通用：

- **加载图像** / **相机单帧采集** → 用与量产一致的矫正图再画；**不清除**已有 ROI（轮廓需重新预览）
- **本页显示旋转**（顺/逆时针 90° 等）→ **不清除** ROI，叠图按旋转后的像素重投影（mm 坐标仍相对矫正图，不是相对旋转后的图）
- **清除 ROI** 才清空当前形状
- 有九点时，对话框里的尺寸按 **mm** 理解；叠图仍是像素

### 1.1 多边形 / 环形路径

1. 选 **直线** 或 **圆弧** 作为下一段。
2. 圆弧可勾 **相切**（与上一段直线/弧光滑；开放轨迹里上一段也可以是**连接线**）。方向不对点 **换向** 或按 `F`。
3. **撤销** `Ctrl+Z`、**重做** `Ctrl+Y`。
4. **`Alt`+点**：强制选中/拖边。画线过程中普通单击是加点，要改已有边请按住 `Alt` 再点。
5. 多边形：终点落在起点容差内自动闭合（「起点容差」单位是屏幕像素）。

### 1.2 开放轨迹

1. 点 **新建本条** → 单击图像即本条**起点**（直线/圆弧保持当前选择；可贴到已有顶点/边）。第一点不弹落点对话框。
2. 点 **完成本条** → 进入选中模式：点边选中/拖动，空白不再加点。
3. 再点 **新建本条** 画下一条。
4. 左侧列表可重命名、编辑选中、删除选中。
5. **连接线**是辅助线，**不进模板**。连接线之后切到圆弧并勾 **相切**，会与该连接线光滑衔接（原先相切只看本条轨迹上一段，连接线后第一段圆弧会失效）。
6. **`Alt`+点**：强制选中/拖边。「新建本条」后进入取点，普通单击是加点、不会选中已有边；此时必须按住 `Alt` 再点才能选边或拖边。「完成本条」后单击即可选边，`Alt` 仍可用。`Ctrl`+拖：整体平移（开放轨迹仅 Ctrl）。
7. **选中一段再拖动或改参数**：与该段顶点相接的其它段、以及吸附在顶点上的连接线/相邻轨迹会**连锁**做同一平移+旋转（不缩放），相对位置和方向保持不变。只改选中段长度时，B 端一侧整体平移，邻段不缩放。`Ctrl`+拖仍是平移全部开放轨迹。
8. **删边**：
   - `Delete` / 右键 **只删此边（其余不动）**：只去掉该段，邻段顶点与圆弧不变。删首/末边只去掉多余端点；删中间边会拆成两条轨迹（后缀名为「原名·后」）。
   - `Shift+Delete` / 右键 **删除并拼接**：去掉该段终点并把后续边接到缺口上（邻接圆弧可能被拉斜）。
   - 多边形已闭合时，删边会在该处断开并保留全部顶点。未闭合多边形不能把中间边拆成两条，请改用开放轨迹。

页上工具栏有随模式变化的提示，点 **编辑说明** 可看当前形状的画法与改法。

保存前若当前条还没「完成本条」，会询问是否先并入再保存。

### 1.3 mm↔像素换算（始终保持平行）

界面上**没有**「保持角度」选项。mm↔像素时固定去掉九点仿射的平面旋转/剪切，只用均匀尺度 + Y 翻转：毫米里平行的线段到图像里仍平行，mm 的 0° 对齐图像 **+X**。保存时 `PreserveRoiAngle` 一律写 `true`；加载时也按此换算，不再读文件里的旧勾选。

## 2. 保存逻辑

按钮：**保存 ROI**。对话框标题为「保存 ROI（mm 坐标）」。

```
当前 UI（有九点则为 mm）
    → 若内存仍是像素：按九点仿射换成 mm（固定保持平行）
    → 写成 Version=2、CoordinateUnit=mm 的 .xvroi.json
```

对话框默认目录为当前流程配方的 `roi/`，默认文件名按当前参数配方（`outline` / `coarse` / `fine`）。建议用这个默认名保存，切换参数配方才能自动对上。

必要条件：

1. 配方里有**有效九点标定**（否则提示无法写成 mm，直接返回）。
2. 当前有可保存的形状（矩形/圆/多边形/环形/开放轨迹），否则提示先绘制。
3. 开放轨迹未完成的草稿：可选「先并入再保存」。

写入字段（摘要）：

| 字段 | 含义 |
|------|------|
| `Version` | 当前为 **2** |
| `CoordinateUnit` | 固定 **`mm`** |
| `NinePointCalibrationPath` | 保存时用的九点 JSON（仅参考；加载时优先配方路径） |
| `PreserveRoiAngle` | 固定 `true`（兼容字段，界面不再提供开关） |
| `ImagePath` / `ImageWidth` / `ImageHeight` | 关联图像（加载时可询问是否打开） |
| `RoiMode` | `rotatedrect` / `circle` / `polygon` / `ring` / `opentrajectories` / `none` |
| 几何 | 矩形中心宽高角、圆心半径、路径顶点/边类型/圆弧经由点、开放轨迹名称与连接线 |

路径顶点与尺寸都是 **mm**，不再把像素写进新文件。

## 3. 加载逻辑

按钮：**加载 ROI**。支持 `*.xvroi.json`、旧版 `*.xvopenpaths.json`、`*.json`。

```
读 JSON
  ├─ 无 RoiMode     → 旧开放轨迹文件，坐标当像素
  ├─ Version < 2    → 一律当像素（CoordinateUnit 强制 px）
  └─ Version≥2 且 CoordinateUnit=mm
        → 需要有效九点标定
        → 内存保持 mm（不要把 mm 再当像素转一次）
        → 叠图 / 创建模板时再 mm→px
```

细节：

1. **九点路径**：以配方 `camera_correction.json` 为准。仅当配方路径为空、且文件里带了存在的 `NinePointCalibrationPath` 时，才用文件路径作回退。
2. **关联图像**：手动点「加载 ROI」时，若 `ImagePath` 存在（绝对路径，或相对 ROI 文件目录），询问是否加载；与当前图尺寸不一致会二次确认。切换参数配方自动加载时**不换图**。
3. **换算**：始终按保持平行做 mm↔像素，忽略文件里旧的 `PreserveRoiAngle=false`。
4. **叠图**：mm 顶点经 `RoiToImagePx` 画到画布；HALCON `GenRegion*` 同样用像素。
5. 日志会写类似：`已加载 ROI: fine.xvroi.json（开放轨迹，mm，叠图像素）`。
6. **切换参数配方**（外框 / 粗匹配 / 精匹配）：自动加载 `roi/outline|coarse|fine.xvroi.json`；文件不存在则 ROI 不动。手动「加载 ROI」仍可选任意文件。

没有九点却去加载 mm 文件会失败（提示需要九点标定）。

## 4. 新旧文件对照

| | 新（v2） | 旧（v1 或缺字段） |
|---|---|---|
| 单位 | `CoordinateUnit=mm` | 像素；无单位字段不得当成 mm |
| 保存 | 必须九点 | 旧开放轨迹 `.xvopenpaths.json` 为像素 |
| 保持平行 | 写入 `PreserveRoiAngle=true`；加载一律按此换算 | 旧文件即使写 false 也按保持平行加载 |
| 加载后再保存 | 仍写成 mm v2 | 会升级为 mm（有九点时） |

## 5. 常见问题

| 现象 | 原因 / 处理 |
|------|-------------|
| 保存提示需要九点 | 先在「① 标定与矫正」配好配方九点 JSON |
| 加载后叠图偏、错位 | 检查当前九点是否与保存时同一份 |
| 加载后图形巨大/缩在一角 | 多半把 mm 当像素。确认文件 `CoordinateUnit` 为 mm，且当前有九点 |
| 切参数配方 ROI 没变 | 对应 `roi/outline|coarse|fine.xvroi.json` 尚未保存过 |
| 开放轨迹少一段 | 保存前点「完成本条」，或在提示里选择并入草稿 |
| 连接线进了模板 | 连接线本就不进模板；检查是否误画成直线段 |

与模板创建、角度/缩放步长的关系见 [README_workflow_guide.md](../README_workflow_guide.md) §3、§3.6。

联调检查清单（ROI → 建模型 → `shape_template_test`）：[README_shape_model_page_test.md](README_shape_model_page_test.md)。
