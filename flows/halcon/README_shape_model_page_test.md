# 形状模板页测试方案：ROI 编辑 → 生成模型 → 测试流程

用于确认 **高级功能 ▾ → 形状模板** 从画 ROI、建模型到跑 `shape_template_test.flow.json` 是否正常。操作细则见 [README_shape_model_roi.md](README_shape_model_roi.md)；匹配参数见 [README_workflow_guide.md](../README_workflow_guide.md) §3、§3.6。

**推荐配方**：流程页先选有九点与测试图的配方（如 `20261028_`：已有 `roi/*.xvroi.json`、`shape_template_test.flow.json`、`models/`）。

**判定**：每条写「期望」。任一条失败即本轮不通过；记录配方名、参数配方、图尺寸、日志最后几行。

---

## 0. 前置

| 项 | 要求 |
|----|------|
| HALCON | 本机构建带 `HALCON_ENABLED` |
| 流程配方 | 已选；`models/camera_correction.json` 指向有效九点 |
| 图像 | 与量产一致的矫正现场图（本页加载或相机单帧） |
| 参数配方 | 内置 **外框模型 / 粗匹配模型 / 精匹配模型** 可切换 |

打开形状模板页后：图能显示、九点摘要有效、侧栏参数配方下拉有三项。

## A. ROI 编辑

### A1 矩形一按一拖

1. 选 **矩形**。若弹出参数框，取消。
2. **清除 ROI**（若已有框）。
3. 在图上按下、拖到对角、松开。

| 期望 |
|------|
| 松开即出现轴对齐矩形，**不必再点一次定角** |
| 再点框内或「参数…」可改中心/宽高/角度 |
| 界面**没有**「保持角度」勾选 |

### A2 圆形一按一拖

1. 选 **圆形**，取消参数框，清除 ROI。
2. 按下圆心、拖半径、松开。

| 期望 |
|------|
| 松开即成圆；再点可改圆心/半径 |

### A3 换图保留 ROI

1. 画好矩形或开放轨迹。
2. **加载图像**（另一张同分辨率现场图）。
3. **相机单帧采集**（有相机时）。

| 期望 |
|------|
| ROI **不消失**，叠在新图上 |
| 轮廓统计变为未提取（需再点「预览轮廓」） |

### A4 开放轨迹连锁

1. 选 **开放轨迹** → **新建本条** → 点图为起点（不弹落点框）→ 再点画直线/圆弧 → **完成本条**。
2. **新建本条** 画第二条（可贴到已有端点）。
3. 选中一段：拖动；改圆弧半径。

| 期望 |
|------|
| 第一点是起点，不是选边 |
| 选圆弧不会被改回直线 |
| 改半径：起点不动、弧度保持、终点移动并带动相连段（平移+旋转，不缩放） |
| 半径小于半弦长时失败/拒绝，**不会**变成巨大圆 |

### A5 保存 ROI

1. **清除 ROI** 后点 **保存 ROI**（应提示没有可保存的形状）。
2. 画矩形，**保存 ROI**。默认目录应为当前流程配方 `roi/`，默认文件名随参数配方：`outline` / `coarse` / `fine.xvroi.json`。确认保存。
3. 用文本打开该 JSON：看 `Version`、`CoordinateUnit`、`RoiMode`、几何。
4. 选 **开放轨迹**，画一条但**不要**点「完成本条」，再保存。选「先并入再保存」。
5. 无九点的配方（若有）再试保存：应拒绝写成 mm。

| 期望 |
|------|
| 空 ROI 不能保存 |
| 有九点时文件为 `Version=2`、`CoordinateUnit=mm`、`PreserveRoiAngle=true` |
| 默认路径能对上当前参数配方，否则切配方不会自动加载 |
| 未完成本条会询问；选并入后文件里有该条 |
| 叠图仍是像素，磁盘坐标是 mm（数值量级是工件毫米，不是几千像素） |

### A6 手动加载 ROI

1. **清除 ROI**。
2. 点 **加载 ROI**，选刚保存的 `.xvroi.json`。若问是否打开关联图像：选否（当前图已对）。
3. 再加载一次，选是（若关联图存在）。
4. 故意加载**另一配方/旧分辨率**的 ROI（若有），看尺寸不一致提示。
5. 加载后立刻再 **保存 ROI** 覆盖同一文件。

| 期望 |
|------|
| 选否：ROI 叠回当前图，形状/尺寸与保存时一致（平行关系保持） |
| 日志类似 `已加载 ROI: ….xvroi.json（矩形/开放轨迹，mm，叠图像素）` |
| 关联图尺寸不一致会二次确认；取消则仍可用当前图 |
| 再保存仍是 mm v2，不会把 mm 再当像素写爆 |

### A7 按参数配方自动加载

1. 选 **粗匹配模型**，保存为 `roi/coarse.xvroi.json`。
2. 选 **精匹配模型**，保存为 `roi/fine.xvroi.json`。
3. 再切回 **粗匹配**，再切 **精匹配**。
4. 选一个**从未保存过**的自定义参数配方（没有则跳过）。

| 期望 |
|------|
| 切到粗/精时自动叠上对应文件，日志 `已加载 ROI: coarse/fine.xvroi.json` |
| 没有对应文件时 ROI **保持原样** |
| 自动加载**不换图**（与手动加载可问关联图不同） |

### A8 会话（切页）保存与恢复

1. 画好 ROI（含开放轨迹更佳），切到流程页再切回形状模板。
2. 关软件再开，进同一配方的形状模板页。

| 期望 |
|------|
| 切页：图、ROI、**已创建的模板**都还在（先出页面再恢复） |
| 重开：能恢复上次图路径与 ROI；若有缓存的 `.shm/.dfm` 则自动加载，不必重建；参数配方为上次所选 |

### A9 撤销与重做

快捷键：**撤销** `Ctrl+Z`（按钮「撤销」），**重做** `Ctrl+Y` 或 `Ctrl+Shift+Z`（按钮「重做」）。**`Alt`+点**强制选中/拖边（取点模式下普通单击是加点）。`Ctrl`+拖整体平移。`Delete` 只删该边，`Shift+Delete` 拼接。

**矩形 / 圆**

1. 拖画出框或圆。
2. 撤销一次。
3. 再重做（若支持）或再画一次。

| 期望 |
|------|
| 撤销后框/圆消失（当前实现是整块清除，不是逐步改尺寸） |
| 清除后重做**不能**把矩形/圆变回来（无顶点栈）；需重新拖画 |

**多边形 / 环形**

1. 多边形：点 4 个顶点（先不闭合）。
2. 撤销两次，再重做两次。
3. 再点闭合；环形则外圈闭合后再画内圈，分别撤销内圈点、外圈点。

| 期望 |
|------|
| 撤销按点倒退；重做按点恢复 |
| 撤销后再**新点一点**，重做栈清空，不能重做被丢掉的点 |
| 未完成圆弧：撤销先取消圆弧草稿，而不是删上一个顶点 |

**开放轨迹**（时间顺序，普通段与连接线同级）

1. **新建本条** → 点起点 + 两点直线 → **完成本条**。
2. **新建本条** → 再画一条（可含圆弧）→ 完成本条。
3. 加一条 **连接线**（若在用）。
4. 选中一段拖动（连锁），松手。
5. 依次撤销，再依次重做，直到回到第 1 步之后、再重做到最后。

| 期望 |
|------|
| 撤销顺序：场景编辑（拖段）→ 连接线 → 完成本条 → 顶点… |
| 撤销「完成本条」后回到优先取点，可继续在该条上加点 |
| 重做能对称恢复；列表条数、名称、连接线与撤销前一致 |
| 拖段撤销后相对位置恢复，不是只动选中段 |
| 撤销到空后再撤销：日志「没有可撤销的步骤」，不崩 |
| 新操作（再加点）后不能重做旧的被覆盖步骤 |

**删除段**

1. 开放轨迹选中一条**中间**边，`Delete`（只删此边）。
2. 再选一端点边，`Delete`。
3. 另选一条边，`Shift+Delete`（删除并拼接）。
4. 开放轨迹下再撤销。

| 期望 |
|------|
| `Delete` 中间边：该段消失，邻段位置/圆弧不变，列表多一条「·后」轨迹 |
| `Delete` 端点边：只少一端，其余不动 |
| `Shift+Delete`：后续边接到缺口（圆弧可能被拉斜） |
| 撤销能回到删除前场景 |

快捷键与按钮应同一效果。焦点须在形状模板页画布/本页，不要在文本框里测 `Ctrl+Z`。

## B. 生成模型

每类模板：**选参数配方 → 确认 ROI 已加载 → 预览轮廓 → 创建形状模型 → 本页测试匹配**。

### B1 预览轮廓

1. 来源与 ROI 贴合目标边（粗匹配常用开放 U / 外框用外轮廓）。
2. 点 **预览轮廓 / 模板域**。

| 期望 |
|------|
| 绿线贴合要匹配的边，无明显背景碎渣 |
| 切到形状模板页应先出界面再恢复会话，不应长时间卡在空白 |

### B2 外框 `.shm`

1. 参数配方 **外框模型**（角度范围宜大）。
2. 预览满意后 **创建形状模型**。
3. 右侧 **测试形状匹配**。

| 期望 |
|------|
| 创建成功，摘要为形状/ScaledShape，不是可变形 |
| 测试能出候选；方向大致对（后续粗匹配靠此外框角） |

### B3 粗匹配 `.shm`

1. 参数配方 **粗匹配模型**（ScaledShape，小缩放窗）。
2. 预览 → 创建 → 本页测试匹配。

| 期望 |
|------|
| 多实例时位置落在工件上，**不要**整板偏到一侧 |
| 分数默认是 HALCON 原始分（`endScoreWeight=0`，不改位姿、不按左右分组） |
| 切走再切回本页，模型与 ROI 仍在 |

### B4 精匹配 `.dfm` / `.shm`

1. 参数配方 **精匹配模型**。
2. 按配方类型创建可变形或缩放形状。
3. 本页测试匹配。

| 期望 |
|------|
| 模型类型与配方一致（精匹配多为可变形 `.dfm`） |
| 轮廓贴边；与粗位姿差应很小（常见约 2° 内，视现场） |

### B5 导出 / 导入模型

1. 创建粗匹配模型后点 **导出模型(.shm)**，保存（默认名可带 `xv_` 参数编码）。
2. **导入模型(.shm)** 同一文件；若已有模型，确认替换。
3. **测试形状匹配**。
4. 精匹配若是 `.dfm`，同样导出/导入 `.dfm`。

| 期望 |
|------|
| 导出文件可被导入；`xv_` 文件名会恢复创建参数（角度范围等） |
| 导入后本页测试仍能匹配 |
| 非 `xv_` 名导入成功但不恢复创建参数（日志说明） |

### B6 替换全局模板（可选，写盘）

点 **替换全局模板**（会覆盖配方 `models/shape_model_outline|coarse|fine.*`）。

| 期望 |
|------|
| 只覆盖当前参数配方对应槽位 |
| 类型不符（配方要 `.shm` 当前是 `.dfm`）会提示，不写错文件 |

## C. 测试流程 `shape_template_test.flow.json`

形状模板页点 **运行模板测试流程**（不要先关本页图）。

行为要点：

- 把本页当前图写入 `models/shape_template_test_input.bmp`，流程读这张图，**不再做一遍矫正**。
- 若本页已创建模型：按参数配方只替换对应槽（外框/粗/精），其它仍用全局 `models/`。
- 流程：`load_image` → 粗匹配子流程 → 循环 → 精子流程 → `display`。
- 部分配方精匹配 `skipMatch=true`：精位姿沿用粗结果，只出轨迹。显示叠的是粗结果时属正常。

### C1 粗匹配槽

1. 当前参数配方 = **粗匹配**，本页已创建粗模型。
2. 运行模板测试流程。

| 期望 |
|------|
| 日志写明替换 `models/shape_model_coarse.shm`（工作副本） |
| 流程跑完；显示窗口有匹配框/轨迹 |
| 候选数合理；**没有**明显定错位（整板错到邻件、单边漂） |
| 连线点开 Score 能看到列表数值 |

### C2 精匹配槽

1. 参数配方 = **精匹配**，本页已创建精模型。
2. 再跑测试流程。

| 期望 |
|------|
| 替换的是 fine `.shm` 或 `.dfm`，与模型类型一致 |
| 轨迹贴工件；`skipMatch=true` 时轨迹与粗位姿一致 |

### C3 未创建模型

1. 清除/不创建本页模型（或新开会话无模型）。
2. 跑测试流程。

| 期望 |
|------|
| 使用配方全局 `models/shape_model_*.shm/.dfm` |
| 全局文件缺失时失败信息指向路径，而不是无提示卡死 |

### C4 切页与时长

1. 测试流程运行中或刚结束，切到流程页再切回形状模板。

| 期望 |
|------|
| 先出现页面，再恢复图/ROI；ROI 不被清掉；**不必重新创建模板**（日志可有「已恢复上次模板」） |

## D. 回归（近期易错）

| # | 操作 | 失败表现 |
|---|------|----------|
| D1 | 矩形拖完松手 | 还要再点一次定角 |
| D2 | 加载图像 / 单帧采集 | ROI 被清空 |
| D3 | 切外框↔粗↔精 | 有文件却不加载，或没文件却把当前 ROI 清掉 |
| D4 | 界面找「保持角度」 | 仍有勾选 |
| D5 | 改行中圆弧半径（如 9→3） | 变成直线或圆变得极大 |
| D6 | 新建本条后点图 | 没落在起点、被当成选边 |
| D7 | 粗匹配一边边缘强 | 另一边轨迹漂掉且分数被左右分组搅乱（已去掉分左右） |
| D8 | 保存后再加载同一 ROI | 尺度炸、错位（mm 被当像素） |
| D9 | 开放轨迹：加点→完成本条→拖段→Ctrl+Z 多次再 Ctrl+Y | 条数错、拖段回不去、完成本条撤不掉 |
| D10 | 多边形撤销后再加点再重做 | 仍重做出已放弃的旧点 |

## F. 自动化（辅助，不能代替本方案）

仓库内 HALCON 冒烟只覆盖算法链路，**不覆盖**画 ROI / 保存 mm / 切配方加载 / 撤销重做：

```text
dotnet run --project XVCalibrate/FlowSmokeTests -- --halcon-coarse-fine
```

（需本机 HALCON 与测试图/模型路径，见 `HalconCoarseFineSmokeTest.cs`。）

本方案以形状模板页人工操作为准。
